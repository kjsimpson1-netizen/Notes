These a key part of the [[design process]] for more complex systems. We can determine what simpler systems (systems with a low number of components) will do given an input because they are determinate, but complex systems have a variety of consequences to each action and are often indeterminate. 
We can use CLD's to determine what will happen to a complex system. Each CLD has several parts:
### How they work
Nodes are where the elements of the CLD will go, and nodes that effect each other will be connected by a directional link. These links can either have positive or negative relationships with the nodes, if it's positive one will constructively effect the other, and it it is negative one will destructively effect the other. 
If there is a closed loop with the overall connection being positive, then this is a reinforcing loop, and if it is negative overall relationship, then this is a balancing loop.
If there is a delay in a link, then this is displayed by a double dash across the link.
