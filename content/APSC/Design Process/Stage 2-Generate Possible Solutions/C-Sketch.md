This stands for <u>collaborative sketching</u>, and is a method of [[Generating Ideas]]. This is done with sketches, without any talking. Each person will sketch their own solution to the problem, and then the solution will get passed around and each person will have a chance to add to each idea. C-sketch can be done an indefinite amount of times, but each round, each team member should try to generate a completely new idea. 
A benefit of C-sketch is that every person will get an equal chance and time to input their opinion on each sketch. This is contrary to brainstorming, where often the louder and more dominant members will have a disproportionally large input, whereas shy members may have no input at all.
