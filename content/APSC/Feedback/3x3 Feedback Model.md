For verbal [[feedback]], it's not only the message that matters, but also how and when it's communicated, with attention paid to body language. The receiver also has the roles now of respectfully receiving the message.
### Message
The message should be [[concrete]], [[complete]] and [[considerate]]. 
### Sender
The sender should make sure to be [[clear]], [[courteous]] and [[considerate]]
### Receiver
The receiver should make sure to be [[clear]], [[courteous]] and [[complete]]
