This is how piano strings and guitar strings work. If there is a standing wave is fixed on both ends, it will still behave very similarly to [[Standing Wave]], however with a few exceptions. For example, in order for these to exist, the length of the string must obey the equation for the nodes, with the length being an integer multiple of half of the wavelength. We can rewrite the equation above in terms of an $n$ integer value:
$
$
\begin{aligned}
L&= n\frac\lambda2\\
\hline\\
L&= \text{Length}\\
\lambda&= \text{Wavelength}\\
n&\in \mathbb{Z}^+
\end{aligned}
$
$
Each of the possible integer values of $n$ also has a corresponding frequency. If it is the first integer, or $n=1$, then this is called the **fundamental frequency**, or $f_1$, of the wave. All consecutive frequencies that follow this equation can be labelled as $f_n$, where $n$ represents that nth integer.
