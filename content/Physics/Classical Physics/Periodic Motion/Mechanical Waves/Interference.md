This is when there are multiple waves that will all interact with each other. This can occur multiple different ways. If we think about a string rigidly attached to a wall, if the string is firmly attached and there is a wave put into the string, the wall will **reflect** the wave, that is send it back to upside down. However if the string is not rigidly attached, then the wave will bounce off the wall with the same direction. 
The attachment to the wall is called the **boundary condition**, and these will determine the behaviour of a wave that interacts with them. This same concept applies when there are two waves travelling at each other. If both waves aren't inverted compared to each other, then their magnitudes will **constructively interfere**, whereas if they are inverted, they will **destructively interfere.** 
>[!Note]
>For light waves to interfere, they must be **coherent** (the same wavelength and monochromatic)
## Constructive Interference
This will occur when the wavelengths interfere with each other at an nth integer wavelength.
$
\begin{aligned}
\lambda &= 1,2,3...
\end{aligned}
$
## Destructive
This will occur when the wavelengths interfere at a half wavelength:
$
\begin{aligned}
\lambda&= \frac12,\frac32,\frac52...
\end{aligned}
$
