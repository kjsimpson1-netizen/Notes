This is a method to solve [[Direct Current]] circuits that is useful when trying to find a [[Voltage]] or when there are few voltage sources. This can be done by taking each of the [[Physics/Electricity and Magnetism/Electric Circuits/Circuit Analysis Techniques/Nodes|Nodes]] that have their own [[Voltage]] (if there are multiple adjacent ones, we can group them together into a super node). From this point, once we have defined all the [[nodes]], we can write a [[Kirchhoff's Junction Law]] for each one, and then we can solve the resulting system of equations.
>[!Note]
>We can choose one of the [[nodes]] to set as our reference [[Physics/Electricity and Magnetism/Electric Circuits/Circuit Analysis Techniques/Nodes|Node]] (the [[Grounding|Ground]]) and this will eliminate one of the systems of equations

>[!Warning]
Whenever there is a voltage source, then we have to take a super node around this, and then write another equation relating the nodes that are a part of the super node
