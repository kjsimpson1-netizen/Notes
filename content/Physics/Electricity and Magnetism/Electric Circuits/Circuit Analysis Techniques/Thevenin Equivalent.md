Any resistor can take any complex circuit, and turn it into a [[resistor]] and a [[voltage]] source in series with the load resistor that is being chosen. This can be done by find the:
## Open Circuit Voltage
We must find the difference across the load resistor as if we removed the resistor from the rest of the circuit. This will give us the Thevenin [[voltage]]
## Short Circuit Current
We must now find the short circuit [[Current]] across the resistor, treating the [[Resistor]] as a short circuit. This will give us the Thevenin [[Current]]
## Thevenin Resistance
We can find this by finding the equivalent [[resistance]], treating the load as the reference point. 
>[!Note]
>We only need to find 2 of the 3 variables, and then we can find the other by using [[Ohm's Law]]
