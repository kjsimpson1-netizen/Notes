There is a upper limit  of [[Electric Potential]] to which a [[Conductor]] in air can be raised to, as if it exceeds this value then the air will ionize and become a conductor itself. This value is $3.0\times10^{6}\frac Vm$. This value is known as $E_m$, or the dielectric strength of air. Therefore, we can also calculate the voltage to which any [[Conductor]] can be raised before it ionizes the air around it using the equation:
$$\begin{align*}
V_m&= RE_m\\
\hline\\
V&= \text{Voltage}\\
R&= \text{Radius}\\
E_m&= \text{Dielectric Strength}
\end{align*}$$
From this equation we can see that if there is a very small radius, there will be a very small amount of [[Voltage]] that can be built up before the object exceeds the [[Dielectric]] strength of the air. When this happens with small objects, it is called _corona discharge_.
