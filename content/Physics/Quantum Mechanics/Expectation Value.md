If we run an experiment many times, the average outcome is called the expectation value. In order to find this value, we can do the following:
$$
\begin{aligned}
\braket{\Psi|\hat O|\Psi}
\end{aligned}
$$
Doing this operation will give the value for the expectation value. 
>[!Warning]
>The expectation value **does not** necessarily represent a true state, rather just the average
