A thermodynamic system is any collection of objects that interact with each other through [[Thermodynamics]]. Any thermodynamic system that has changes done can be thought of as a thermodynamic process. In thermodynamic systems, it is crucial that we clearly identify which of the object make up the system, and which parts are not included. 
## Thermodynamic Work and Heat
In thermodynamic systems, we describe the energy relations in terms of quantities of [[Heat]] (represented by "Q") added and [[Work]] (represented by "W") done <u>by</u> the system. It is important to note the difference between the [[Work]] done by the system and the [[Work]] done on a system as they will have opposite signs. A positive Q value indicates that there is [[Heat]] added to a system, and a negative implies that there is [[Heat]] taken away. A positive [[Work]] implies that the gas does positive [[Work]] on it's surroundings (expansion) and a negative [[Work]] implies that is does negative [[Work]] on it's surrounding (contraction). 
## Work done during Volume Changes
Whenever there is a container of gas that changes size due to [[Thermodynamics]], there is work being done by the gas. Note that if there is no change in size, there is no [[Work]] being done, even though there may be a force exerted. We can find how much work is done using a small amount of calculus:
$$\begin{align*}
W&= F\cdot d\\
dW&= F\cdot dx
\end{align*}$$
And because the work here is being done due to a change in [[Pressure]], we can rewrite it as:
$$\begin{align*}
dW&= PA\cdot dx\\
\\
A\cdot dx&= dV\\
\\
dW&= P\;dV
\end{align*}$$
We can then find the total amount of work done by taking the integral of this:
$$\begin{align*}
W&= \int_{V_1}^{V_2}P\;dV
\end{align*}$$
