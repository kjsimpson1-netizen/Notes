This is the same principal as with [[Linear Expansion]], but as a volume instead. This applies to both liquids and solids. This is characterised by an equation very similar to that of [[Linear Expansion]]:
$
\begin{aligned}
\Delta V=\beta V_0\Delta T
\end{aligned}
$
With $\beta$ representing the volumetric coefficient of expansion.
### Relation between Solid's Volumetric and Linear Expansion
Considering a cube, where the volume is shown by the expression $V=L^3$, we can use some calculus to show the relationships between $\alpha$ and $\beta$. We can start this problem using Related Rates
$
\begin{aligned}
V&= L^3\\
dV&=(3L^2)\;(dL )
\end{aligned}
$
Using the other equation for $dL$, ($dL=\alpha L_0dT$) we can directly substitute it in to the equation above giving us:
$
\begin{aligned}
dV&= (3L^2)(\alpha L\;dT)\\
&= 3\alpha L^3dT
\end{aligned}
$
And since $V=L^3$, we can replace this in the equation to give us:
$
\begin{aligned}
dV&= 3\alpha V_0\;dT
\end{aligned}
$
Comparing this to the equation $dV=\beta V_0\;dT$, we can see that $3\alpha=\beta$
