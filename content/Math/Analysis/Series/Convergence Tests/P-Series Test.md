This is the [[Convergence Tests]] to see if $x$ raised to a power will converge or not. The value for p depends which axis the function is approaching. For this explanation, we will take the p-test to be with reference to:
$
$
\begin{aligned}
f(x)=\frac1{x^p}
\end{aligned}
$
$
## Horizontal
If the function is approaching the x axis, then $p\in(1,\infty)$ will give us convergence, as we need it to approach the asymptote quickly
## Approaching the y-axis
If the function is approaching the y-axis or a vertical asymptote, then $p\in(0,1)$ will give us convergence.
