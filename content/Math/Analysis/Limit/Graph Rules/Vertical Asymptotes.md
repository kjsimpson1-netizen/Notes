To find the vertical asymptotes of a certain function, factor the denominator and any answers for 0 will be the locations of the vertical asymptotes, because the Function will evaluate to be [[Infinity]]. 
```desmos-graph
y=x/{(x^2-1)}
```

## Limit
We can also see this as a [[Limit]], because the [[Limit]] as the function approaches the value (but doesn't reach it) will approach [[Infinity]].
$$
$$\begin{aligned}
\lim_{x\rightarrow a}f(x)&= \pm\infty
\end{aligned}$$
$$
