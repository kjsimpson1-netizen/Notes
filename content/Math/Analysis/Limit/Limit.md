A limit states that $L=\lim_n\to\infty$ if $\forall\epsilon>0$, $\exists N\in\mathbb{N}$ such that $\forall n\in \mathbb N$  $n>N\implies|a_n-L|<\epsilon$. A limit is the value that function approaches with a given value. A limit does not necessarily have to be equal to the true value of the function, and it is rather the value that is agreed upon by the limit as it approaches from the bottom and the top
$$\begin{align*}
\lim_{x\rightarrow0}f(x)&\neq f(x)\\
\lim_{x\rightarrow0^-}f(x)= \lim_{x\rightarrow0}&f(x)=\lim_{x\rightarrow0^+}f(x)
\end{align*}$$
