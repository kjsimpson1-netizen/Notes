This is one of the methods to evaluate a [[Limit]] where there is no [[Indeterminate Form]], or the function won't evaluate to [[Infinity]]. If either of these are true, then we must use [[L'Hopitals Rule]].
To do direct substitution the graph <u>must</u> have [[Continuity|Continuity]] on that [[Interval]]. This is when the value that the [[Limit]] is approaching is directly substituted into the function and this will give you the value as a [[Limit]].
$
\begin{aligned}
\lim_{x\rightarrow a}f(x)&= f(a)
\end{aligned}
$
