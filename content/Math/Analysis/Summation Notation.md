This is used when there is repeated addition of many similar terms, and for this we use the symbol $\Sigma$. We can also write it as the following:
$$\begin{align*}
x&= a+b+c...+z
\end{align*}$$
However this is imprecise, and can be expressed more clearly and elegantly with the sigma notation:
$$\begin{align*}
&\sum\limits_{k=m}^nf(k)\\
\hline\\
n&= \text{Upper Bound}\\
m&= \text{Lower Bound}\\
k&= \text{Index}\\
f(k)&= \text{Function}
\end{align*}$$
This can be read as the summation of the $f(k)$ from $m$ to $n$, where $m$ and $n$ are both [[Integers]] defined on the domain of $f(k)$.
>[!Note]
>If there is a scalar multiplication inside the summation, you can factor it out, or:
>$$\begin{align*}
\sum k\cdot f(x)&= k\sum f(x)
\end{align*}$$
This also work well with sums and differences:$$\begin{align*}
\sum f(x)+g(x)=\sum f(x)+\sum g(x)
\end{align*}$$However the function must occur on the same interval
