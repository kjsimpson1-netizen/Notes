A set is a collection of objects. The objects inside of it are referred to as [[elements]] or [[Elements|Members]]. Usually mathematics using capital letters for sets. The only thing a set can "tell" us, is whether or not it contains a certain [[Elements]]. 
## Declaring a Set
We must make the definition of a set being clear with a clear definition. This can be done by just listing out the set in curly braces i.e.:
$
\begin{aligned}
B=\{1,2,3\}
\end{aligned}
$
>[!Note]
>There is no order for a set and the repetition of the same [[Elements|Element]] in a set does not matter

We can also define a larger set using ellipses "$\dots$" and can be shown as
$
\begin{aligned}
B=\{1,2,\dots,10\}
\end{aligned}
$
This can be used when the context is clear. We can also write the elements using a rule such as:
$
\begin{aligned}
A=\{x\;|\;x\text{ is even}\}
\end{aligned}
$
Where the pipe "|" reads "so that".
