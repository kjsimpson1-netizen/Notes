This is the [[Derivative]], but done backwards from the [[Derivative Rules]]. The notation for an antiderivative is the capital of the function, or $F(x)$.
## Zeros
If there is a zero for the function, this means that there was a constant there before, since the derivative of a constant is 0. This is where the [[Constant of Integration]] comes from
## Polynomials
The definition of this is:
$$\begin{align*}
&&f(x)&= x^n\\
&\therefore&F(x)&= \frac1{n+1}x^{n+1}+C
\end{align*}$$
This can be done with any variable raised to a constant power (with the exception of $-1$). 
## Exponentials
For the antiderivative of an exponential (base $e$), we can follow the following formula:
$$\begin{align*}
&&f(x)&= e^{nx}\\
&\therefore&F(x)&= \frac1ne^{nx}+C
\end{align*}$$
## $\frac1x$
This is a special case, and it is:
$$\begin{align*}
f(x)&= \frac1x\\
F(x)&= \log|x|+C
\end{align*}$$
Note the absolute value here, because the antiderivative must be defined on all values.
## Trigonometry
These are the antiderivatives of the following functions
#### $\sin(x)$
$$\begin{align*}
f(x)&= \sin(x)\\
F(x)&= -\cos(x)+C
\end{align*}$$
#### $\cos(x)$
$$\begin{align*}
f(x)&= \cos(x)\\
F(x)&= \sin(x)+C
\end{align*}$$
#### $\sec^2(x)$
$$\begin{align*}
f(x)&= \sec^2(x)\\
F(x)&= \tan(x)+C
\end{align*}$$
#### $\frac1{\sqrt{1-x^2}}$
$$\begin{align*}
f(x)&= \frac1{\sqrt{1-x^2}}\\
F(x)&= \arcsin(x)+C
\end{align*}$$
#### $-\frac1{\sqrt{1-x^2}}$
$$\begin{align*}
f(x)&= -\frac1{\sqrt{1-x^2}}\\
F(x)&= \arccos(x)+C
\end{align*}$$
#### $\frac1{{1+x^2}}$
$$\begin{align*}
f(x)&= \frac1{{1+x^2}}\\
F(x)&= \arctan(x)+C
\end{align*}$$
