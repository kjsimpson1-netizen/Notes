This is a method for solving for the [[Antiderivative]] of a function to evaluate the [[Indefinite Integral]]. This is useful when you can see the [[Derivative]] of one function present inside the integrand. This can be thought of as the reverse of the [[Chain Rule]]. For example:
$$
\begin{aligned}
\int(2x+1)\cos(x^2+x)dx
\end{aligned}
$$
Here we can see the derivative of the argument inside the cosine function. We can declare this as the term "$u$". When we are done with the substitution, we can either re-substitute the variable $x$ or we can express the [[Bounds]] in terms of $u(x)$.
>[!Note]
>The part that we want to substitute, the $u$, is very important, as the derivative of the function **must** be present in the integrand for this to work. It is still possible if it is not present, however we will have to back substitute and this can make it excessively complicated
