When we zoom in on a point, $(a,f(a))$, on the graph of $y=f(x)$, the function looks like it's [[Tangent Line]]. 
Therefore, we can approximate $f(x)$ by it's [[Tangent Line]], $T(x)$, when $x$ is sufficiently close to $a$.
>[!Note]
>This is a first order [[Taylor Polynomials]]
### Equation
The linear approximation of $f(x)$ at $x=a$ is:
$$\begin{align*}
L(x)=f(a)+f'(a)\cdot(x-a)
\end{align*}$$
We can find the linear approximation by plugging the chosen value $a$ and then simplifying the expression. 
>[!Note]
>When we pick the points, we must pick points that we know things about the function. Otherwise, there is not point in making an approximation that is harder to compute.
