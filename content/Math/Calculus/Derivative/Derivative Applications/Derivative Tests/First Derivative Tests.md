These can be used to either determine the behaviour of a the rate of change of a function at a certain point (increasing, decreasing, staying the same or non existent) using the first [[Derivative]], or to find the local and global extrema. 
## Extrema
These are points at which there is a [[Critical Points]], [[Singular Point]], or [[End Points]], and when they switch signs as well.
>[!Note]
>For endpoints, they do not have to switch sign, as they only have one sign to reference to
### Local vs. Global
If it is a local extrema, this means that the values on either side of it are less extreme than it. If it is a global extrema, this means that every value on the [[Interval]] is less extreme than it. The only way to find the global extrema is to check all the local extrema and then take the most extreme of these.
>[!Note]
>If there is an infinite [[Discontinuity]], this means that there is no extrema whether it be local or global) there, as there is no single value that it will approach
### Maxima
This is point at which there are no other points that are more positive than it, and this is where the first [[Derivative]] will switch from positive to negative.
### Minima
This is the point at which there are no other points that are more negative than it, and this is where the first [[Derivative]] will switch from negative to positive. 
>[!Note]
>We can also use the [[Second Derivative Tests]] to determine whether or not it is a local min or max
