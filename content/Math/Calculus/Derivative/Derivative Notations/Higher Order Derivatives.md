Just as with regular [[Derivative|Derivatives]] and [[Leibniz Notation]] we can add the squares to indicated the nth derivative being taken, we can do the same thing with [[Partial Derivatives]]. However, since there are usually multiple variables, we can also do the derivatives with respect to multiple variables n different times. The notation for this is:
$$\begin{align*}
\frac{\partial^2 f}{\partial x\partial y}
\end{align*}$$
This is an example of a function $f$ being differentiated first with respect to $x$ and with respect to $y$.
>[!Note]
>The order with which we take the derivatives does not make any difference (provided both [[Partial Derivatives]] exist and are [[Continuity|Continuous]]). This is proved by Schwarz's Theorem and it states that:
>$$\begin{align*}
\frac{\partial ^2f}{\partial x\partial y}=\frac{\partial ^2f}{\partial y\partial x}
\end{align*}$$
