This is how a given [[System]] responds when a [[Unit Impulse]] is put into the function. This is very useful, as if we have the the impulse response, we can figure out how the system will respond to any [[Signal]]. These are denoted with $h(t)$:
$$
\begin{aligned}
h(t)=\mathcal{L}\{\delta (t)\}
\end{aligned}
$$
