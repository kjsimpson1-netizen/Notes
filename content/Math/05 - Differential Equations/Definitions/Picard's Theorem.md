When dealing with an [[Ordinary Differential Equations|ODE]], we want to make sure that the solution exists, and if it does, is it a unique solution? We can determine this using Picard's Theorem, which states:
>[!Theorem]
>If $f(x,y)$ is [[Continuity|Continuous]] and (as a function of two variables) $\frac{\partial f}{\partial y}$ exists and is [[Continuity|Continuous]] near some $(x_0,y_0)$, then a solution to:
>$$
\begin{aligned}
\begin{cases}
y'=f(x,y)\\y(x_0)= y_0
\end{cases}
\end{aligned}
$$
Exists and is unique
