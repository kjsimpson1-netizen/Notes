This is an [[Ordinary Differential Equations|ODE]] that does not explicitly depend on an independent variable. For example, $y=y'$ is autonomous, however $y(t)t= y'(t)$ is not. 
## Critical Points
In these problems, whenever $y'=0$ these are called critical points. This is because the everything on these points will stay there. However, with slight perturbations, there are three types of critical points:
- **Stable** This is when slight perturbations occur, the solution decays back to the point
- **Unstable** When a slight perturbation occurs, the solution moves away from the point
- **Semi-Stable** This is when a perturbation occurs, the solution moves towards or away based on which side it moves away.
