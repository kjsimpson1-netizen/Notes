This is the math for the chances of any event happening. This is represented by a random variable, which is a characteristic or measurement that can be determined for each outcome of some event. These are usually represented by capital letters. If the variable is a number in a range, then it is continuous, however if it is a discrete number then it is not continuous.
## Notation
The notation of the probability is given by $Pr(X)$. The function $Pr(X)$ gives us the likelihood of some event happening, and the range of the probability function are $Pr(X)\in[0,1]$.
