These are any function that include $\sin,\;\cos\text{ or }\tan$  in some way. 
### $\sin(x)$
```desmos-graph
\sin(x)
```
This passes through the point $(0,0)$ and the range of this function is $[-1,1]$. 
### $\cos(x)$
```desmos-graph
\cos(x)
```
This is the exact same as $\sin(x)$, but translated $\frac12\pi$ radians left. The point $(0,1)$ always lies on this curve, and it also has a range of $[-1,1]$
### $\tan(x)$
```desmos-graph
\tan(x)
```
As this is the [[Rational Functions]] of $\sin(x)$ and $\cos(x)$, we can see where the function approaches [[Infinity]] and will have [[Vertical Asymptotes]] due to the denominator, $\cos(x)$ approaches 0, which can be expressed by:
$$
$$
\begin{aligned}
x&= n\pi+\frac12\pi
\end{aligned}
$$
$$
However it's range spans all real numbers. It passes through the origin, as $\sin(x)$ is 0 here. The function also is equal to $\pm1$ when the two functions are equivalent, which occurs when:
$$
$$
\begin{aligned}
x&= \frac14n\pi+\frac14
\end{aligned}
$$
$$
