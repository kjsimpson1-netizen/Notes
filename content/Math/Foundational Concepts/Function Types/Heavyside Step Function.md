This is a function using in [[Circuit Analysis Techniques]] for things like [[Capacitor]] and [[Inductor]], as well as in [[Ordinary Differential Equations]] for [[Laplace Transforms]]. This is a function such that the following is true:
$
$
\begin{aligned}
u(t)&= \begin{cases}
0&t\in(-\infty,0)\\
1&t\in[0,\infty)
\end{cases}
\end{aligned}
$
$
This can then be modified using any combination of reflections and translations.
