These are any function with the variable in the exponent, meaning that as the x value increases, the y-value increases exponentially. 
>[!Note]
>Exponential functions will always have a positive y-value, as there isn't a power that you can raise a number to in order to make it a negative
```desmos-graph
e^x
```
The higher the base of the exponent, the more aggressively that the function is at low and higher values of x. This means that it will behave "more exponentially", as in it will decrease faster and increase faster. 
>[!Note]
>Any exponential function will pass through the point $(0,1)$, as any base to the 0th power will be 1. 

Another feature of exponential functions is that given enough time, they will grow more aggressively (meaning their [[Derivative]] will have a higher value) than any [[Power Function]].
We commonly use the base $e$ because it behaves very well with calculus, being that it's value is equivalent to it's [[Slope]], or [[Derivative]].
