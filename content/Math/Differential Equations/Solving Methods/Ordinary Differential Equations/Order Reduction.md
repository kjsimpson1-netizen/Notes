This is a method for solving a higher [[Order]] [[Ordinary Differential Equations|ODE]] by reducing the order of the [[Ordinary Differential Equations|ODE]] this can be done if we know one of the two solutions. Assuming we know one of the two [[Solutions]], then we can express the answer as:
$
$
\begin{aligned}
y_2(x)&= y_1(x)\int\frac{e^{-\int p(x)dx}}{(y_1(x))^2}dx
\end{aligned}
$
$
Where $p(x)$ is the coefficient function of the first order derivative in the differential equation.
