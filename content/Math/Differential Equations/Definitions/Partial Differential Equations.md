These are [[Math/Differential Equations/Differential Equations|Differential Equations]] which are done with respect to many different independent variables and these are more complicated than [[Ordinary Differential Equations]]. Given a PDE, an equation relating various [[Partial Derivatives]] of some function $u$. Solving this means finding the (or family of) functions that satisfies the equation.
