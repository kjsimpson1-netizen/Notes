This refers to the highest degree of the [[Derivative]] that is being taken. For example, a first order differential equation is one which only contains a first order [[Derivative]]. 
#### Examples
$
\begin{aligned}
\text{Function}&&\text{Order}\\
\hline
y'+y&= \cos(t)&&1\\
y^{(3)}(t)&= \frac1{1+t^2}&&3\\
y^{(27)}+y&= 0&&27\\
\ddot y+\dot y&= x^6&&2
\end{aligned}
$
