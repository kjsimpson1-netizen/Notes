This is when there is a [[Linear Transformation]] that is a [[Linear Transformation]] of another, denoted by the notation:$$\begin{align*}
T_1\circ T_2(\vec x)
\end{align*}$$In order to do this, we keep it in the current order and then do the [[Matrix Multiplication]] of each of each [[Linear Transformation]].
>[!Warning]
>The second [[Linear Transformation]] must go first
