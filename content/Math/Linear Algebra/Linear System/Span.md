This is defined to be smallest linear [[Subspace]] of a vector space $V$ that contains the set $S$. We can think of this as the fewest amount of orthogonal [[Vector|Vectors]] required to fully define a plane.
For example, the span of [[Vector|Vectors]] $\vec u_1+...+\vec u_m\in\mathbb{R}^n$ is the set of all [[Linear Combinations]]:
$$
\begin{aligned}
\text{span}\set {\vec u_1,...,\vec u_m}&= \set {c_1\vec u_1+...+c_m\vec u_m\in\mathbb{R}^n:c_1,...,c_m\in \mathbb{R}}
\end{aligned}
$$
>[!Note]
>The span of the set $u$ is a a [[Subspace]] of $\mathbb{R}^n$
