When we are given a linear system, the first subscript is the row, and the second is the column. For example:
$$
$$
\begin{aligned}
\begin{cases}
a_{11}&a_{12}&a_{13}&\dots &a_{1n}&=&C_1\\
a_{21}&a_{22}&a_{23}&\dots &a_{2n}&=&C_2\\
a_{31}&a_{32}&a_{33}&\dots &a_{3n}&=&C_3\\
\vdots&\vdots&\vdots&\ddots&\vdots&&\vdots\\
a_{n1}&a_{n2}&a_{n3}&\dots &a_{nn}&=&C_n
\end{cases}
\end{aligned}
$$
$$
We can think of this as finding the point at which three [[Planes]] intersect. There can either be one single point at which the equations are satisfied, at multiple points, or even infinite points. We can also write the linear system above as an [[Augmented Matrix]].
