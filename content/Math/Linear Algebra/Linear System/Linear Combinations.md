A linear combination is when a set of [[Vector]]s are multiplied by a [[Scalar]] and then summed together:
$
$
\begin{aligned}
\vec b&= s_1\vec a_1+s_2\vec a_2\dots s_m \vec a_m&m\in \mathbb{N}
\end{aligned}
$
$
>[!Note]
>If you can write one vector as a linear combination of another, then they have [[Linear Independence]]
