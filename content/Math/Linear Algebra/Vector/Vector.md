This is any quantity that is determined by 2 or more [[Scalar]]. A point in $\mathbb{R}^2$ is in a 2 dimensional space, with the exponent denoting the amount of dimensions that the vector exists in. (For example, $\mathbb{R}^3$ is a 3 dimensional vector). 
Vectors are often represented with a lower case letter with the vector arrow over it (for example $\vec{a}$ is the vector of acceleration). It can also be represented by a bolded lower case letter (for example $\textbf{a}$ is also the vector of acceleration). 
Each of the [[Scalar]] in a vector is called a component, or an entry (although entries usually refer to matrices). The order of the components is extremely important, and must be consistent among all vectors. 
>[!Note]
>The tail of the vector arrow does not necessarily have to be connected to the origin, as long as the vector has the same magnitude and direction, then it is the same vector. 
## Magnitude
This is the length of the vector, or the size, and can be found using the [[Norm]] of the vector. 
## Adding and Subtracting
You can add and subtract vectors by just subtracting/adding each of the corresponding components in the vectors. 
$$\begin{align*}
\vec{a}\pm\vec{b}&= (a_1\pm b_1,a_2\pm b_2)
\end{align*}$$
## Multiplying a vector by a scalar
If you are multiplying a vector by a scalar, then you distribute the scalar throughout each of the components of the vector. 
$$\begin{align*}
c\vec{a}&= (ca_1, ca_2)
\end{align*}$$
All this does is scale the length of the vector, not the direction (unless it is negative.)
