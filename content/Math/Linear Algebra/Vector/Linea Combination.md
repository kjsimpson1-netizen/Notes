This is the same idea as the [[Cartesian Coordinates]], but instead of using $\hat i,\hat j, \hat k$ , we will use the letter $e$ with a subscript representing which coordinate it refers to. For example:
$
\begin{aligned}
\vec e_1&= (1,0,0 ...)\\
\vec e_2&= (0,1,0 ...)\\
\vec e_3&= (0,0,1 ...)
\end{aligned}
$
